# Support Guide 🤝

Thank you for using text2handwriting.me! We want to make sure you get the help you need as quickly as possible.

## ❓ Have a Question?

If you have a question about how to use the app, technical setup, or general inquiries, please:

1. **Open a [GitHub Discussion](https://github.com/bipin-vishwakarma/text2handwriting.me/discussions)**: Best for technical questions and community help.
2. **Open an Issue**: Ask directly on the [Issue Tracker](https://github.com/bipin-vishwakarma/text2handwriting.me/issues).

## 🐞 Found a Bug?

Please report it using [GitHub Issues](https://github.com/bipin-vishwakarma/text2handwriting.me/issues).

## ✨ Feature Requests

We love hearing your ideas! Suggest them via [GitHub Feature Requests](https://github.com/bipin-vishwakarma/text2handwriting.me/issues).

## 🔒 Security Vulnerabilities

Please do **not** open a public issue for security concerns. Refer to our [Security Policy](SECURITY.md).
